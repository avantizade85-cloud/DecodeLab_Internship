# DecodeLab Data Science Internship – Project 2

## 🚨 Fraud Detection Using Machine Learning

### 📌 Project Overview

This project is completed as part of the **DecodeLab Data Science Internship – Project 2**.

The project focuses on detecting fraudulent transactions using **Machine Learning classification algorithms**.

The main objective is to analyze transaction data, preprocess the data, handle class imbalance using **SMOTE**, train machine learning models, and compare their performance using different evaluation metrics.

The following models are implemented:

* Logistic Regression
* Random Forest Classifier

---

## 🎯 Objectives

* Load and explore the fraud transaction dataset.
* Analyze missing values and duplicate records.
* Understand fraud and genuine transaction distribution.
* Encode categorical variables.
* Split data into training and testing sets.
* Apply feature scaling.
* Handle class imbalance using SMOTE.
* Train Logistic Regression and Random Forest models.
* Evaluate model performance.
* Compare both models.
* Identify important features.
* Save results and visualizations.

---

## 📊 Dataset

The project uses a fraud transaction dataset containing transaction-related information.

### Important Columns

| Column             | Description                   |
| ------------------ | ----------------------------- |
| `Transaction_ID`   | Unique transaction identifier |
| `Location`         | Transaction location          |
| `Transaction_Type` | Type of transaction           |
| `Fraud`            | Target variable               |

### Target Variable

```text
0 → Genuine Transaction
1 → Fraudulent Transaction
```

## 🛠️ Data Preprocessing

### Categorical Encoding

Categorical features such as `Location` and `Transaction_Type` are converted into numerical features using **One-Hot Encoding**.

### Train-Test Split

The dataset is divided into:

* 80% Training Data
* 20% Testing Data

Stratified splitting is used to maintain the fraud class distribution.

### Feature Scaling

`StandardScaler` is used to standardize the features before model training.

### SMOTE

Fraud datasets are often imbalanced because genuine transactions are much more common than fraudulent transactions.

**SMOTE (Synthetic Minority Oversampling Technique)** is applied to the training data to balance the classes.

---

## 🤖 Machine Learning Models

### 1. Logistic Regression

Logistic Regression is used as a baseline classification algorithm for predicting fraudulent transactions.

### 2. Random Forest Classifier

Random Forest is an ensemble learning algorithm that uses multiple decision trees for classification.

It is also used to determine the most important features for fraud detection.

---

## 📏 Model Evaluation

The models are evaluated using:

* **Precision**
* **Recall**
* **ROC-AUC**
* **Confusion Matrix**
* **Classification Report**
* **ROC Curve**

The model having the highest ROC-AUC score is selected as the best-performing model.
